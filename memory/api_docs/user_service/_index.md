# User Service API Index

## 版本说明

### v1/ - 基础版本 (15个接口)
- 包含用户管理的基础功能
- 简单的认证和资料管理

### v2/ - 增强版本 (12个接口)  
- 支持邮箱注册和验证
- 多种登录方式
- Token 刷新机制
- 批量操作增强
- 高级搜索和筛选
- 用户活动记录
